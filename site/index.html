Press. Slide. Let go.

No app window to open, no website to upload to.

Press and hold a file

On the desktop, hold a file for half a second. A ring of actions opens around the pointer.

Slide to an action

Only the actions that work for that file are shown. Groups such as Office open a second ring.

Let go

The new file appears next to the original. The original is left exactly as it was.

Prefer menus? Right-click any file in Finder and choose MaruDoc.

After you open it

  1. MaruDoc walks you through two switches on first launch.
  2. Right-click menu: System Settings, General, Login Items & Extensions, Finder, turn on MaruDoc.
  3. Press and hold: System Settings, Privacy & Security, Accessibility, turn on MaruDoc. It is used only to find the file you pressed and follow the pointer.

Questions

Is it really free?

Yes. No trial, no subscription, no in-app purchases, no account.

Are my files uploaded anywhere?

No. Every conversion and edit runs on your Mac and works the same with Wi‑Fi off. The only time MaruDoc goes online is when you choose Check for Updates, which reads the latest version number from marudoc.app. Conversion, text recognition and background removal use frameworks built into macOS. See the privacy policy.

Will it get in the way of normal clicks and drags?

No. The ring only opens when you press and hold a file for half a second without moving. You can change the delay in settings or turn press and hold off.

Can it convert scanned PDFs?

Yes. Pages without text go through text recognition first, so the result has real, searchable text.

Is there a Mac App Store version?

Yes, on the Mac App Store. It has the right-click menu only, because press and hold needs permissions that the App Store does not allow. For the full app, use the download above.

Which Macs does it run on?

Any Mac with macOS 14 Sonoma or later, Apple silicon or Intel.

How do I uninstall it?

Quit MaruDoc from the menu bar and move it from Applications to the Trash. Or run curl -fsSL https://marudoc.app/install.sh | sh -s -- --uninstall.
